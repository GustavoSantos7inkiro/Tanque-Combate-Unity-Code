# Canhão de Combate – A Batalha Final

C# source code from a game developed with Unity.

## Apresentação

Repositório destinado à apresentação dos scripts de programação desenvolvidos por mim para o jogo Canhão de Combate – A Batalha Final.

## Sobre o projeto

Canhão de Combate – A Batalha Final é um jogo desenvolvido utilizando Unity e C#.

Este repositório contém somente os scripts de programação desenvolvidos por mim.

As artes, músicas, efeitos sonoros e demais recursos produzidos por outros integrantes da equipe não foram incluídos, com o objetivo de respeitar a autoria e os direitos dos respectivos criadores. Cenas, prefabs e outros arquivos necessários para executar o projeto completo também não fazem parte deste repositório.

Por esse motivo, esta versão é destinada à demonstração de código e não representa o projeto completo executável.

## Minha contribuição

Fui o único programador do projeto, responsável pela implementação completa do jogo em C# na Unity.

- Desenvolvimento e configuração do projeto no editor da Unity
- Programação dos controles dos tanques
- Implementação do sistema de disparos e projéteis
- Implementação dos sistemas de vida e dano
- Criação do sistema de terreno e blocos destrutíveis, inspirado em Gunbound
- Implementação do sistema de estamina
- Criação de um sistema de cooldown após cinco disparos consecutivos
- Programação das interações e mecânicas de gameplay
- Implementação da identificação e diferenciação dos jogadores
- Implementação da interface e do sistema de vitória
- Testes, identificação e correção de erros
